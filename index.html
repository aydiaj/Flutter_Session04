STEP 02 · ARRAYS → DART LISTS11 MIN

Arrays in Dart? Meet List<T>

Dart does have arrays in the everyday sense: arrays are List objects. There is no separate built-in int[] declaration for ordinary Dart arrays. For specialized binary buffers, Dart also provides fixed-size typed-data classes such as Uint8List in dart:typed_data; those are not the everyday List API. Compare the languages you already know before touching the syntax.

C# · FIXED ARRAY

int[]

int[] scores = {72, 85, 90};

Fixed length, strongly typed; use List<int> for dynamic resizing.

JAVASCRIPT · ARRAY

Array

const scores = [72, 85, 90];

Resizes; allows mixed types unless constrained separately (e.g. TypeScript).

DART · LIST

List<int>

final scores = <int>[72, 85, 90];

Indexed, typed, normally growable. final protects the variable binding, not the elements.

Dart list basics

A List<T> preserves order and permits duplicates. Indexes start at 0; last index = length - 1. List<String> contains strings, and var scores = [7, 9] infers List<int>. Using the wrong element type is a static error; using an invalid index raises a RangeError.

STEP 03 · LIST OPERATIONS14 MIN

Creating and modifying Lists

Know the difference between changing an element, changing a List’s length, and preventing all changes. These details are not identical to C# arrays or JavaScript Arrays.

GROWABLE

[1, 2, 3] and <int>[]

Ordinary literals create growable lists. Use add, addAll, insert, remove, removeAt and removeLast.

FIXED LENGTH

List.filled(n, value)

The default List length is fixed. Existing positions can be updated, but adding or removing fails unless growable: true.

READ-ONLY CONTENT

List.unmodifiable(...)

No element replacement or length changes. A const List literal is also immutable.

NESTED LISTS

List<List<int>>

Represent tables or matrices using grid[row][column]. Validate both index levels.

Reference semantics: assigning is not copying

Three important copy cases for Lists

Like JavaScript arrays and C# reference-type collections, a Dart List is an object. So the question is not only “did I make another variable?” but “did I make another structure?” Keep these three cases separate:

Option 1 · No copy

Shared reference

Use final b = a;.
Both names point to the same List object.

final a = [10, 20, 30];
final b = a;

b[0] = 99;
// a and b both become [99, 20, 30]
Option 2 · Shallow copy

New outer List

Use List.of(a), List.from(a), or [...a].
The outer List is new, so changing a top-level element does not change the original. 

final a = [10, 20, 30];
final b = [...a];

b[0] = 99;
// a stays [10, 20, 30]
// b becomes [99, 20, 30]
Option 3 · Nested caveat

Inner objects still shared

A shallow copy only copies the outer List. If the items are Lists or other mutable objects, the inner objects are still shared.

final a = [[1, 2], [3, 4]];
final b = [...a];

b[0][0] = 99;
// a also changes to [[99, 2], [3, 4]]

What “shallow copy” really means

final b = a; gives you a second name for the same object. A shallow copy such as List.of(a), List.from(a), or [...a] gives you a new outer List. That is enough for one-dimensional Lists of numbers, strings, and other simple values. But for nested Lists, a shallow copy does not clone the inner Lists. To make nested structures independent, copy the inner Lists too, for example [for (final inner in a) [...inner]].

04 · No copy, shallow copy, and nested Lists

Run the code and compare the three situations: same object, new outer List, and shallow copy with nested Lists.

main.dart · Dart · Copying Lists
void main() {
  // 1) No copy: shared reference
  final numbers = [10, 20, 30];
  final same = numbers;
  same[0] = 99;
  print('numbers:      $numbers');
  print('same:         $same');
  print(identical(numbers, same)); // true

  // 2) Shallow copy: new outer list
  final original = [1, 2, 3];
  final copy = [...original];
  copy[1] = 200;
  print('original:     $original');
  print('copy:         $copy');
  print(identical(original, copy)); // false

  // 3) Nested lists: inner lists still shared
  final nested = [
    [1, 2],
    [3, 4],
  ];
  final nestedShallow = [...nested];
  nestedShallow[0][0] = 500;
  print('nested:       $nested');
  print('nestedShallow:$nestedShallow');

  // To separate nested lists too:
  final nestedIndependent = [for (final inner in nested) [...inner]];
  nestedIndependent[1][1] = 900;
  print('nestedIndep:  $nestedIndependent');
  print('nested after independent copy: $nested');
}

STEP 05 · SETS09 MIN

Sets: unique values, useful operations

A Set is not another array. Use it when uniqueness and membership matter more than indexed positions.

LIST[ Dart, SQL, Dart ]Duplicates allowed
→
SET{ Dart, SQL }Duplicates removed

Set<T> rules

A Set contains unique elements, offers add, addAll, remove, contains, and set algebra: union, intersection, difference. It has no indexed set[0] access. In standard Dart, Set literals generally use insertion-ordered sets, but you should not rely on index access as an API. An empty Set is <String>{}; plain {} creates a Map.

STEP 07 · COLLECTION ELEMENTS10 MIN

Collection if, collection for and spread

One of Dart’s most useful differences from familiar loops: build collections directly inside [], {}, and Maps with control-flow elements.

A for element is not a normal for body

In [for (final x in values) x * 2], each evaluated expression contributes one element. No explicit .add() or return is needed. An if element contributes an element only if its condition matches. These can be nested.

STEP 08 · DART A · CASCADES10 MIN

Cascades: operate on one object

Primary reference for this topic: Dart A, Chapter 3, “Taking advantage of the cascade operator.” This is not merely syntactic sugar for calling methods in a chain.

WITHOUT CASCADE 
final values = [3, 1, 2];
values.insert(0, 8);
values.sort();

Repeat values for each operation.

WITH CASCADE 
final values = [3, 1, 2]
  ..insert(0, 8)
  ..sort();

Every .. operates on the original List

Why the return type matters

Ordinary method chaining, object.methodA().methodB(), calls methodB on the return value of methodA. Cascades, object..methodA()..methodB(), keep the original receiver regardless of individual method return values. ?.. starts a null-shorting cascade when the original receiver may be null; it skips subsequent cascade operations if null.

STEP 09 · FUNCTIONS & SCOPE11 MIN

Functions: define, return, reuse

Putting everything inside main() does not scale. Dart functions make behavior reusable and prepare you for Flutter methods and callbacks.

Function anatomy

A normal Dart function has a return type, name, parameter list and body: int add(int a, int b) { return a + b; }.
void means the function does not return a useful value.
return sends a result (if any) to the caller and ends the function.
The => arrow shorthand only supports a single expression (with the return keyword omitted) and cannot contain a multi-statement block.

STEP 10 · PARAMETERS11 MIN

Positional, optional and named parameters

This is the most Flutter-relevant function topic: most widget constructors use named parameters.

REQUIRED POSITIONALint sum(int a, int b)

Call sum(2, 3); order matters.

OPTIONAL POSITIONALf(int x, [int y = 1])

Brackets [] and default values.

OPTIONAL NAMEDf({bool enabled = false})

Curly braces; named arguments can appear in any order.

REQUIRED NAMEDf({required String name})

required forces the caller to supply the name.

Null safety meets parameters

A named parameter without required must either have a default value or allow null (e.g. String? title). A function can have required positional parameters followed by named or optional positional parameters, not both groups together. required can make a named argument mandatory even when its type is nullable.

STEP 11 · FUNCTION OBJECTS & CALLBACKS10 MIN

Arrow functions, callbacks and higher-order functions

Dart treats functions as objects: you can assign one to a variable, pass it to another function, and return a function. The C# equivalents include delegates/lambdas; JavaScript has first-class functions.

Arrow, anonymous, callback, higher-order

Use int square(int n) => n * n; for one expression.
An anonymous function has no name, e.g. (n) { print(n); }. Passing it to forEach makes it a callback.
Any function that receives or returns another function is higher-order. Typed signatures such as int Function(int) convey the exact contract.

Closures (Quick Concept)

A closure is a function that "remembers" variables from where it was created, even after the outer function finishes.
For example: 

Function makeAdder(int step) {
  // This inner function remembers 'step'
  return (int n) {
    return n + step;
  };
}

The inner function remembers step even after makeAdder has finished, the exact same concept Flutter uses when a button handler needs to remember data from your screen.

double average(List<int> scores) {
  if (scores.isEmpty) return 0;
  var total = 0;
  for (final score in scores) { total += score; }
  return total / scores.length;
}
void summary({required String module, required List<int> scores}) {
  final unique = scores.toSet();
  print('$module | ${scores.length} entries | ${unique.length} unique');
  print('Average: ${average(scores).toStringAsFixed(1)}');
}
