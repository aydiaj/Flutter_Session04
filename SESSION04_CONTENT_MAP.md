# Coverage map · 120 minutes

1. Prior-knowledge check (8)
2. Arrays in Dart → `List<T>`, C# / JavaScript comparisons, index/length (11)
3. Growable/fixed/unmodifiable/nested lists; add/insert/remove; reference semantics and copies (14)
4. for/indexed, for-in, forEach, useful List methods, map/where (12)
5. Sets, uniqueness and set algebra (9)
6. Maps, nullable lookup, keys/values/entries and forEach (10)
7. Collection for / if, spread and null-aware spread (10)
8. **Dart A** cascades with insert/sort and UrlBuilder; null-shorting cascade (10)
9. Functions, return types, void, block/function/top-level scope (11)
10. Required and optional positionals, optional and required named arguments, default values/nullability (11)
11. Arrow/anonymous functions, callbacks, higher-order functions, typed signatures, closures (10)
12. Integrated practice, PDF homework and exit check (4)

**All core content is documented, but 120-minute teaching has to prioritize demonstrations:** additional independent exercises and advanced function behavior are explicitly self-study extensions. Instructor may extend into another class if student pacing requires.
