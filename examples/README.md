# Session 04 · 19 DartPad exercise starters

Each `examples/<key>/main.dart` matches exactly one `data-activity="<key>"` in `index.html` and one key in `js/gists.js`.

The Gists are not created automatically. Run `python tools/publish_gists.py` for a dry-run, then provide a private `GITHUB_TOKEN` with gist permission and run `python tools/publish_gists.py --publish` from your own computer. Never commit tokens to the repo. Until Gists are configured, students can copy code into dartpad.dev or run `dart run examples/<key>/main.dart` locally.

The downloadable homework is separate from the public code examples; do not publish instructor answers as starter Gists.
